# 实施范围与验收状态

本版本是可运行工程原型，不能代替已完成微调与实际企业验证的最终竞赛作品。

| 子系统 | 本版本状态 | 后续验收 |
|---|---|---|
| 案例与文档 | 已实现版本、哈希去重、引用、原文定位 | 独立复杂格式解析集 |
| 文本 PDF、DOCX、XLSX | 已实现；扫描页与未缓存公式明确提示 | PP-Structure OCR 尚待集成和标定 |
| 抽取与规则 | 已实现标签式字段抽取、差异、策略阈值、行金额核对 | 自由格式抽取依赖模型质量 |
| 语义模型 | 原始Qwen独立接口及三类最小虚构文本测试通过，带原文引用校验 | 尚未训练专业Adapter；不视为独立效果评测 |
| 工作流 | LangGraph 持久化、人工中断、版本审批、重试 | 长时间故障注入与多服务压测 |
| 数据库 | 远程原型使用 SQLite WAL；SQLAlchemy 支持 PostgreSQL | Docker/PG 组合尚未在当前主机验证 |
| 队列 | 原型使用单进程后台任务与持久化输入 | Celery 调度尚待实现；不宣称已有分布式队列 |
| 知识 | 原创解释库、快照、关键词召回；提供本地 dense/RRF/重排接口 | 权威材料整理、BGE 模型及 pgvector 索引验收待完成 |
| 报告 | JSON、TXT、PDF、DOCX 导出 | 格式结构测试已覆盖；专业内容与排版需扩充案例复核 |
| 数据集 | 20 条明确标记 pending 的合成候选及审核发布工具 | 3000/500/800 人工审核数据未完成 |
| 模型训练 | QLoRA 配置、GPU 检查、人工审核门槛 | 未产出正式 Adapter；需审核数据后训练 |
| 模型评测 | 独立 API 客户端、封存样本门槛与诊断指标 | 完整风险 Macro-F1、消融、置信区间与用户试用待完成 |

原型只支持单租户、单 API worker。网页使用工作区 Basic Auth，后端使用访问密钥；工作区身份不是多用户 RBAC。远程回环访问仍需通过 SSH 隧道，避免在明文 HTTP 上暴露凭据。不得将该配置直接用于对外公开业务。

安全检查会拒绝有任何计算进程的指定 GPU，包括显存为零或进程无法从容器内解析的条目。锁只能协调本项目，无法替代集群调度器的资源预约；有调度器时应在获配设备内运行。
