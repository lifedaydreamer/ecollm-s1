原型只支持单租户、单 API worker。网页使用工作区 Basic Auth，后端使用访问密钥；工作区身份不是多用户 RBAC。可分发 Demo 在使用者自己的设备生成独立密码，默认只绑定本机；开发服务器的回环访问使用 SSH 隧道。公开多人业务需要独立权限与部署验收。

安全检查会拒绝有任何计算进程的指定 GPU，包括显存为零或进程无法从容器内解析的条目。锁只能协调本项目，无法替代集群调度器的资源预约；有调度器时应在获配设备内运行。

新增 `showcase/` 静态交互预览和 Docker 一键启动，详见 README 与自行运行指南。展示页使用四个虚构案例的规则结果快照，不运行或冒充模型推理。模型 Docker 配置支持使用者自己的本地权重与可选 Adapter，GPU 容器路径仍需独立环境验收。

本轮补充：显式 SKU 关联与数量/单价比较，重复/缺失 SKU、单位和币种不明时人工核验；企业策略界面编辑；修订问题变化清单；历史审查快照只读；模型差异双边证据与原文位置校验；28 场景 CPU API 工程回归。

完整竞争力分析与需要专业人员参与的工作见 [COMPETITION_READINESS.md](COMPETITION_READINESS.md)。工程回归与独立效果评测分别报告，不能混用。

## CUAD 专项试训更新（2026-10-20）

已产出九类商务合同条款抽取的真实 LoRA 实验 Adapter，完成 711/54/72 分组训练与固定提示词对照。测试证据 token F1 58.05%→73.00%，条款存在判断 Macro-F1 58.32%→88.66%。详见 [训练报告](TRAINING_REPORT.md)。正式外贸风险多任务训练、三种子/强基线、业务接口适配与真实用户评测仍未完成，默认 Agent 继续使用原模型。
