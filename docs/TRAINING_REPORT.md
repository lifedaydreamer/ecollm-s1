# TradePilot-Clause-4B：CUAD 首轮 LoRA 训练与对照报告

报告日期：2026-10-20。状态：**公开数据子集上的实验模型，已完成真实训练与冻结测试；尚未接入智能体默认路径。**

本轮证据支持继续准备赛道一方向二的“商务合同条款识别与证据抽取”作品。比赛中的外贸风险审查、完整文档任务和真实用户收益仍须另行验证。

## 1. 做了什么

基于 Qwen3-4B-Instruct-2507，对 CUAD 九类商业合同条款进行 LoRA 微调。输入是请求类别与英文片段；输出是 found / not_found_in_excerpt 以及逐字原文引句。没有将条款标签改写为未经专业审核的风险等级，也不推断整份合同缺失条款。

九类为责任上限、责任限制例外/无限责任、违约金、保证期限、保险、审计权、任意解除、准据法和最低承诺。类别语义沿用 CUAD，而非法律效力结论。

## 2. 数据与隔离

- 来源：[CUAD v1 官方数据](https://github.com/The-Atticus-Project/cuad)，CC BY 4.0；The Atticus Project，Hendrycks、Burns、Chen、Ball（NeurIPS 2021）。
- 训练 / 验证 / 测试：711 / 54 / 72 个片段任务，分别来自 234 / 34 / 43 个发行主体前缀分组。
- 标签继承上游专家引句，精确校验字符位置；没有新增人工风险标签。
- 保留官方测试合同，移除与其发行主体前缀相同的 17 份训练候选合同；验证也按主体分组，跨组排除完全相同的标准化片段。
- 固定 1600 字符窗口、1200 字符步长；移除 1733 个切断标注引句的候选窗口。因此本结果仅适用于这个过滤子集。
- 来源别名、近重复模板和基座预训练污染尚不能完全排除；不是完整 CUAD 官方榜单成绩。

完整身份、各类数量与文件校验值见 [数据清单](training/cuad-data-manifest.json)。数据切片是衍生转换，保留来源归属、许可、合同标题和标注 ID。

## 4. 公平对照与测试结果

两模型使用相同片段、提示词、贪心解码、最大输出长度和 JSON 约束。验证集完成预设增益检查后才运行冻结测试，未依据测试结果调整超参数。基础提示词尚未进行系统优化，这也是后续需要补充的强基线。

**测试集：72 条任务、43 个来源分组。**

| 指标 | 原始基座 | 微调 Adapter | 变化 |
|---|---:|---:|---:|
| 证据 token F1 | 58.05% | 73.00% | +14.95 个百分点 |
| 条款存在判断 Macro-F1 | 58.32% | 88.66% | +30.34 个百分点 |
| 完整引句集合匹配率 | 38.89% | 59.72% | +20.83 个百分点 |
| 每条实际输出引句的原文匹配率 | 83.33% (20/24) | 93.33% (42/45) | +10.00 个百分点 |

证据 token F1 是本项目对引用内容进行分词重叠的平均分；空引用的正确未检出也计分。条款 Macro-F1 是九类请求上的“存在”正类 F1 平均，**不是外贸风险 Macro-F1**。完整引句集合匹配率同时要求类别状态与所有引句完全一致。实际引句匹配率的分母仅含已输出的引句。

原始记录另包含“回答中所有引句均可定位”的比例：基座 94.44%、微调 95.83%。其中合法空证据回答计为通过，不能与逐条引句匹配率混用。两模型 JSON 合法率均为 100%，但这是在相同结构化输出约束之后测得，不当作微调收益。

证据 token F1 的配对来源分组 Bootstrap 提升区间：**+4.76 至 +25.30 个百分点**（95%，2000 次重采样，统计种子 20261020）。此区间仅反映本子集的数据分组波动，不包含训练随机种子差异和真实外贸分布变化。

72 条测试中：**28 条改善、13 条退化、31 条不变**。完整分组统计与退化 ID 见 [测试分析](training/test-analysis.json)。

## 6. 一个真实修正案例

这是从验证集中选出的修正漏检案例，用于说明行为，不代表整体成绩。类别：Uncapped Liability。

原始模型：`not_found_in_excerpt`。

微调模型：`found`，引句与上游标注完全一致：

> Except with respect to any claim or liability arising from an infringement of any third party intellectual property right, in no event shall either party be liable for any special, indirect, consequential, punitive or incidental damages of any kind.

该类标签指 CUAD 对责任限制例外等条款的归类，不代表系统已判定合同的法律效力。完整上下文和两份输出见 [案例记录](training/validation-example.json)。

## 8. 距离方向二正式作品还剩什么

1. 做优化提示词基线与固定配置的三随机种子复验，报告均值、波动和失败类别。
2. 补充外贸付款、交付、责任关联与跨文档变化任务；新风险标签需要专业复核。公开商业合同条款能力不能直接当作真实外贸业务能力。
3. 完善长条款与完整合同的检索、分段、引用校验；本轮过滤窗口不能证明长文覆盖。
4. 将合格条款模块作为工具接入 Agent，并单独进行端到端与用户试用。
5. 补齐模型卡、数据卡、使用指南、模型对照报告与演示视频；报名与成果复用以竞赛正式规则为准。

本轮源码新增模块后的 22 项工程测试、28 场景业务回归通过；GPU 试训与公开数据评测是独立路径，分开报告。
