## 调试中发现并处理的问题

初始模型输出不满足接口结构。加入 JSON 解码约束，并将外部知识引用保留为后端添加，消除约束库处理自由字典时的兼容问题。进一步明确单合同 review 与双文档 compare 的输入边界，清除非本任务输出，保留所有覆盖限制。

首次完整案例中语义审查超时，仅保留规则结果，该次测试未计为语义成功。随后移除重复的派生事实输入、跳过已被明确标签规则覆盖的重复抽取，并限制生成时长和返回项数量；覆盖范围限制仍保留。

最后一次部署集成记录位于服务器 `.data/integration-result.json`，原始测试与业务数据不提交到公开仓库。

一次模型重启时 GPU 利用率超出阈值，资源防护拒绝启动。未放宽阈值、自动换卡或停止其他进程；后续资源检查显示空闲后才重新启动。
